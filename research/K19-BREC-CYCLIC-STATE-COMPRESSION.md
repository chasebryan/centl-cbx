# k=19 BREC cyclic-state compression

**Status:** exact finite computer-assisted state theorem  
**Date:** 2026-08-17  
**Application:** `CBX-Lane-I-shift-history-v1`  
**Claim boundary:** fixed-shift state compression only; not an Erdős–Straus proof

## 1. The fifth predecessor coordinate is naturally cyclic

For a Mordell-hard prime `p`, put

```text
C = C_19 = (p+19)/4.
```

Because `p` is not `19`, the integer `C` is a unit modulo `19`.

The unit group

```text
U(19)
```

is cyclic of order `18`, and `2` is a primitive root. Write every prime factor residue as

```text
q_i = 2^(a_i) mod 19,
```

and expand multiplicity so that each prime valuation contributes one atom `a_i` in `Z/18Z`.

If

```text
C = product_i q_i,
```

then its product exponent is

```text
c = sum_i a_i mod 18.
```

The exact signed box becomes the exponent sumset

```text
S = sum_i {-a_i,0,+a_i}  subset Z/18Z.
```

This representation is exact because a prime power `q^e` contributes the interval of signed exponents

```text
-e,-e+1,...,e,
```

which is precisely the e-fold sum of `{-1,0,+1}`. Expanding valuation into repeated atoms therefore changes no signed-box state.

## 2. The two exact targets have simple exponents

At fixed `k=19`,

```text
p = 4C mod 19.
```

Since

```text
4 = 2^2,
-1 = 2^9,
```

we have

```text
p = 2^(c+2) mod 19.
```

Therefore the exact target exponents are

```text
Type II : 9
Type I  : 9-(c+2) = 7-c mod 18.
```

Hence the fifth BREC coordinate is negative exactly when

```text
9 not in S
and
7-c not in S.
```

The important difference from `k=3,7,11,15` is that the Type-I target genuinely moves with the product exponent `c`. A fixed subgroup label alone is therefore too crude for the full k19 obstruction.

## 3. Finite exact state automaton

Define the state

```text
E = (c,S).
```

The empty factorization starts at

```text
E0 = (0,{0}).
```

Adding one valuation atom `a` applies the exact transition

```text
c' = c+a mod18,
S' = S + {-a,0,+a}.
```

There are only finitely many possible states because `c` has 18 values and `S` is a subset of `Z/18Z`.

The verifier exhausts the closure under **all 18 possible residue atoms**. The exact result is

```text
reachable states                         439
combined-miss states                     136
maximum canonical atoms, all states        4
maximum canonical atoms, miss states       3
```

The closure is checked after enumeration: every one of the 439 states remains inside the enumerated set under every possible next atom.

This is therefore not a finite prime census. It is an exhaustive computation in the finite unit-group state space.

---

## 4. State compression theorem

Every exact k19 signed-box state is residue-equivalent to a canonical state generated by at most four valuation atoms.

More sharply:

```text
every combined k19 miss state
has a canonical representative using at most 3 atoms.
```

This is a **state complexity bound**, not a factor-count bound.

An actual `C_19` may contain arbitrarily many prime factors or large valuations. Additional factors can act redundantly in the finite cyclic state space and collapse onto a state with a much shorter canonical representative.

Do not rewrite the theorem as

```text
Omega(C_19) <= 3.
```

That statement is not proved and is generally not what the finite-state result means.

## 5. Exact depth distributions

The 439 reachable states have canonical-depth distribution

```text
depth 0      1
depth 1     17
depth 2    133
depth 3    287
depth 4      1
```

The 136 combined-miss states have

```text
depth 0      1
depth 1     15
depth 2     77
depth 3     43
```

No combined miss requires canonical depth 4.

The unique depth-4 state is

```text
c = 0,
S = Z/18Z,
```

so it has full signed support and is necessarily constructive.

## 6. Miss support sizes

Every signed-box support is symmetric under exponent negation and contains zero. Since a combined miss cannot contain exponent `9`, the observed exact miss support sizes are odd.

The complete miss-state support-size distribution is

```text
|S| =  1      1 state
|S| =  3     16 states
|S| =  5     19 states
|S| =  7     20 states
|S| =  9     42 states
|S| = 11      8 states
|S| = 13     15 states
|S| = 15     14 states
|S| = 17      1 state
```

The largest possible combined miss has support size 17. It is unique:

```text
c = 16,
S = Z/18Z \ {9}.
```

In that state the only absent unit exponent is the Type-II target itself. Combined failure is still possible only because

```text
7-c = 9 mod18,
```

so the Type-I target coincides with the same missing exponent.

This is a useful warning: enormous signed-box occupancy alone does not force construction when the two targets collapse onto one residual hole.

## 7. Translation onto the q23 rescue parameter

On the exact q23 Type-I-only normal form,

```text

p    = 24T-23.
```

The fifth predecessor is

```text
C_19 = 6T-1.
```

Thus a full `-----` ancestry requires the exact cyclic state of `6T-1` to lie in one of the 136 obstruction states.

The preceding four coordinates already constrain

```text
6T-5,
3T-2,
2T-1,
3T-1.
```

The k19 theorem adds a finite state constraint on

```text

```

This completes an exact normal-form language for all five predecessor positions before the q23 target. The remaining work is now cross-coordinate: determine which combinations of the five exact obstruction grammars can coexist for the same `T` under the q23 rescue normal form.

## 11. Claim boundary

This is an exhaustive finite-group state theorem at fixed `k=19`.

It does not bound the number of prime factors of `C_19`, does not prove that only finitely many primes miss at k19, does not grant pruning authority to BREC, does not establish a universal finite Lane-I ceiling, and does not prove Erdős–Straus.
