# k=3 BREC obstruction normal form

**Status:** exact elementary lemma  
**Date:** 2026-08-17  
**Application:** `CBX-Lane-I-shift-history-v1`

## 1. Statement

Let `p` be a Mordell-hard prime and define

```text
C_3 = (p+3)/4.
```

Then the exact combined Lane-I state at `k=3` is obstructive,

```text
sigma_3(p) = -,
```

if and only if

```text
every prime divisor q of C_3 satisfies q = 1 mod 3.
```

Equivalently,

```text
sigma_3(p) = +
```

if and only if `C_3` has at least one prime divisor congruent to `2 mod 3`.

This is a genuine exact normal form for the first BREC coordinate, not a finite-census observation.

---

## 2. Hard-prime residue input

The Mordell-hard residue classes modulo 840 are

```text
1, 121, 169, 289, 361, 529.
```

Every one is

```text
1 mod 4
and
1 mod 3.
```

Therefore for a Mordell-hard prime `p`,

```text
p = 1 mod 3.
```

Since `4 = 1 mod 3`,

```text
C_3 = (p+3)/4 = 1 mod 3.
```

In particular,

```text
gcd(C_3,3)=1.
```

---

## 3. The two k=3 targets coincide

At an admissible Lane-I shift the two exact signed-box targets are

```text
Type II: -1
Type I : -p^(-1).
```

Modulo 3,

```text
-1 = 2.
```

Because

```text
p = 1 mod 3,
```

we also have

```text
p^(-1) = 1 mod 3,
```

and hence

```text
-p^(-1) = 2 mod 3.
```

So at `k=3` the nominally two-target Lane-I condition collapses to one exact target:

```text
Type I = Type II = 2 mod 3.
```

---

## 4. Signed-box support modulo 3

Write

```text
C_3 = product q_i^(e_i).
```

The signed box contains residues represented by

```text
product q_i^(z_i) mod 3,
where -e_i <= z_i <= e_i.
```

Because `gcd(C_3,3)=1`, every prime divisor is either

```text
1 mod 3
or
2 mod 3.
```

If every prime divisor is `1 mod 3`, every signed product is `1`, so

```text
R_3(C_3) = {1}
```

and the target `2` is missed.

Conversely, suppose some prime divisor `q_j` is `2 mod 3`. Since `e_j >= 1`, choose

```text
z_j = 1
```

and choose exponent zero for every other factor. Then the signed product is

```text
2 mod 3.
```

Thus the target is hit.

This proves the stated equivalence.

---

## 5. BREC interpretation

The first BREC coordinate is therefore unusually transparent:

```text
+  <=> C_3 has a prime divisor 2 mod 3
-  <=> every prime divisor of C_3 is 1 mod 3
```

So a leading `-` in a Lane-I BREC history is an exact multiplicative monoid condition:

```text
C_3 belongs to the monoid generated by primes q = 1 mod 3.
```

No probability or heuristic language is required.

## 6. Relation to k=23

Because

```text
C_23 = (p+23)/4
```

and

```text
C_3 = (p+3)/4,
```

we have the exact translation

```text
C_3 = C_23 - 5.
```

The `k=3` obstruction condition can therefore be written directly on a `k=23` candidate:

```text
every prime divisor of C_23 - 5 is 1 mod 3.
```

This is the correct exact compatibility condition to impose on the `q=23` Type-I rescue branches.

The companion classification developed alongside BREC reduces those rescue branches, conditional on the known `q=23` Type-II miss normal form, to exactly

```text
5^2
or
14^2
```

nonresidue valuation patterns modulo 23.

So the current Type-I companion problem admits the concrete simultaneous form:

```text
q23 rescue branch:
    C_23 has a same-class valuation-two 5^2 or 14^2 defect,

k3 obstruction:
    every prime divisor of C_23 - 5 is 1 mod 3.
```

Explicit larger witnesses show that these conditions are compatible, so this lemma does **not** rescue the discarded target-coincidence conjecture. Its value is that it turns the first BREC obstruction into an exact factor condition that can be carried into later branch analysis.
