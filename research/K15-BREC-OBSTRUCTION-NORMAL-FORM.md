# k=15 BREC obstruction normal form

**Status:** exact unit-group/coset lemma  
**Date:** 2026-08-17  
**Application:** `CBX-Lane-I-shift-history-v1`

## 1. Statement

Let `p` be a Mordell-hard prime and

```text
C_15 = (p+15)/4.
```

Then the exact combined BREC state at `k=15` is obstructive if and only if every prime divisor of `C_15` lies in the order-four subgroup

```text
H_15 = <2> = {1,2,4,8} mod 15.
```

Equivalently,

```text
sigma_15(p) = -
iff
q mod 15 in {1,2,4,8}
for every prime q dividing C_15.
```

Any prime divisor in the other unit-group coset

```text
-H_15 = {7,11,13,14}
```

forces a combined construction for a Mordell-hard prime.

---

## 2. Hard-prime input

Reducing the six Mordell-hard residue classes modulo 15 gives only

```text
p mod 15 in {1,4}.
```

Since

```text
4^(-1) = 4 mod 15,
```

we get

```text
C_15 = p*4^(-1) mod 15
```

and therefore

```text
C_15 mod 15 in {4,1}.
```

Both residues lie in `H_15`.

Every Mordell-hard prime is also

```text
1 mod 8.
```

Hence

```text
p+15 = 0 mod 8,
```

so `C_15` is even. The factor `2` is therefore forced.

---

## 3. The subgroup generated by the forced factor

Modulo 15,

```text
2^1 = 2
2^2 = 4
2^3 = 8
2^4 = 1.
```

Thus

```text
H_15 = <2> = {1,2,4,8}.
```

If `v2(C_15)=1`, the local signed exponents `{-1,0,+1}` give

```text
{2^(-1),1,2} = {8,1,2},
```

which is `H_15` with `4` missing.

If

```text
v2(C_15) >= 2,
```

then exponents `-2,-1,0,1,2` are available and the factor `2` alone fills all of `H_15`.

Likewise, with `v2=1`, any additional prime factor in

```text
H_15 - {1}
```

fills the whole subgroup together with the forced factor `2`.

So subgroup support can fail to saturate only in the thin skeleton

```text
v2(C_15)=1
and
all other H_15 prime factors are 1 mod 15.
```

---

## 4. Both exact targets live in the other coset

The Type-II target is

```text
-1 = 14 mod 15,
```

which lies in

```text
-H_15 = {7,11,13,14}.
```

For a Mordell-hard prime, `p mod15` is `1` or `4`.

If

```text
p = 1 mod 15,
```

then

```text
-p^(-1) = 14.
```

If

```text
p = 4 mod 15,
```

then `4^(-1)=4`, so

```text
-p^(-1) = -4 = 11 mod 15.
```

Thus the Type-I target is always in `-H_15` as well.

It follows immediately that if every prime divisor of `C_15` lies in `H_15`, the signed box remains inside `H_15` and both targets miss.

---

## 5. Full subgroup support plus one outside factor

Suppose the signed box already contains all of `H_15` and some prime divisor `q` lies in `-H_15`.

Choosing signed exponent `+1` on `q` gives `q`, and multiplication by the full subgroup gives

```text
q H_15 = -H_15.
```

Therefore the signed box contains both cosets:

```text
H_15 union -H_15 = (Z/15Z)^x.
```

So both targets hit.

The only possible loophole is the thin subgroup skeleton from Section 3.

---

## 6. Eliminate the thin loophole with the hard residue condition

Write

```text
H_15 = <a>,  a=2,
```

and write the other coset as

```text
-H_15 = {-a^j : j=0,1,2,3}.
```

Explicitly:

```text
j=0 -> 14
j=1 -> 13
j=2 -> 11
j=3 -> 7.
```

With only the thin forced support

```text
{1,2,8},
```

a factor in class:

```text
14
```

reaches the Type-II target directly.

A factor in class

```text
13 or 7
```

combines with `{1,2,8}` to reach both target positions `14` and `11`.

The only outside class that can avoid Type II in isolation is

```text
11 = -4.
```

Therefore a hypothetical thin combined miss with outside factors would have to use **only** prime factors congruent to `11 mod15` outside the subgroup.

But `C_15` itself lies in `H_15`, so the total number of outside-coset factors counted with multiplicity must be even.

For even `m`,

```text
11^m = 1 mod 15.
```

The thin subgroup factors contribute only the forced residue `2`, because all other subgroup factors are `1`.

Hence such a state would force

```text
C_15 = 2 mod 15.
```

This contradicts the hard-prime requirement

```text
C_15 mod15 in {1,4}.
```

So the thin loophole cannot occur for a Mordell-hard prime.

This completes the proof.

## 7. Exact normal form

We therefore have the exact equivalence

```text
sigma_15(p) = -
iff
every prime divisor q of C_15=(p+15)/4 satisfies
q mod15 in {1,2,4,8}.
```

This fourth BREC coordinate is simpler than the `k=11` coordinate: after the hard congruence is used, no thin exceptional miss branch survives.
